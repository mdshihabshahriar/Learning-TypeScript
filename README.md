# TypeScript Learning

A hands-on repository for learning and practicing **TypeScript** from the fundamentals to Object-Oriented Programming (OOP) and modern development setup using **Vite**.

## 📚 Topics Covered

### 1. TypeScript Fundamentals

* Variable declaration and assignment
* Basic data types
* Type annotations
* Type inference
* Arrays and tuples
* Objects
* Functions
* Union and intersection types
* Type aliases
* Interfaces
* Enums

### 2. Object-Oriented Programming (OOP)

* Classes and objects
* Constructors
* Properties and methods
* Access modifiers
* Encapsulation
* Inheritance
* Polymorphism
* Abstraction
* Interfaces with classes

### 3. TypeScript with Vite

* Creating a TypeScript project with Vite
* Project structure
* TypeScript configuration
* Running the development server
* Building the project for production

## Technologies

* TypeScript
* JavaScript
* Vite
* Node.js
* npm

## Learning Goals

The main goals of this repository are to:

* Build a strong foundation in TypeScript
* Understand static typing and type safety
* Practice Object-Oriented Programming
* Learn how TypeScript works with modern frontend tooling
* Become comfortable with Vite-based TypeScript projects
* Apply TypeScript concepts through practical exercises and projects
